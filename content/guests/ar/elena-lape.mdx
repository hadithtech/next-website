# إيلينا لابي

إيلينا لابي هي مؤسسة Holopin، المنصة التي تساعد المجتمعات على تقدير مساهميها عبر الشارات الرقمية. عملت سابقاً في GitHub على حزمة المطور الطلابية، وهي مناصرة للمطورين والشركات الصغيرة والمصادر المفتوحة.
