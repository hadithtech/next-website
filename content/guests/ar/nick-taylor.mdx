# نيك تايلور

نيك تايلور مهندس برمجيات ونجم GitHub وحاصل على لقب Microsoft MVP. ينشط في المصادر المفتوحة ويشارك معرفته بسخاء مع مجتمع المطورين عبر البث المباشر والكتابة والمحاضرات.

## الخبرات

- تطوير الويب
- TypeScript و JavaScript
- المصادر المفتوحة
- تعليم المطورين

## معروف بـ

- كونه نجم GitHub وحاصلاً على لقب Microsoft MVP
- البث المباشر ومشاركة نصائح المطورين
- المساهمة في المصادر المفتوحة

## تواصل

تابع نيك للحصول على نصائح تطوير الويب والبث المباشر ورؤى حول المصادر المفتوحة.
