# Episode 7: Open Source Contribution with Forest Anderson

Forest Anderson, core developer of Veloren and Rust Gamedev Working Group team lead, joins us to talk about open source contribution.

## Topics Covered

- Getting started with open source contributions
- Working on Veloren, an open source game written in Rust
- Building communities around open source projects
- Lessons for new contributors

## About the Guest

Forest Anderson is a GitHub Campus Expert, core developer of Veloren, and Rust Gamedev Working Group team lead.
